# Poker Table — Darts + Levels 50–100 website

## Protect your existing saves

This is a complete static website, not a deployment, account or automatic update.
An attachment does not change an already hosted website. Export a private JSON
backup of each important slot before updating. Keep the SAME existing origin and
directory, and replace the complete website bundle together. Never clear site
storage, reset a slot or move to another domain to install an update.

Close every older game/survey tab and Home Screen window after finishing pending
actions. Reopen the approved HTTPS URL online to obtain the complete update.
A failed, incomplete or mixed release must not replace the active offline bundle.
Do not minify, rewrite or inject into the packaged files: their exact bytes are
verified. Serve JavaScript and media with their correct MIME types, the manifest
as application/manifest+json, and sw.js with revalidation/no-cache.

## Browser, slots and uncertain saves

Progress belongs to this browser and origin. Safari and a Home Screen web app may
have different storage contexts; another device or domain does not inherit it.
JSON/cloud transfer replaces only the selected slot, not every slot. Account login
is shared by the browser but is not archived in individual slots. Cloud actions
contact the configured service only when explicitly requested.

Modern same-origin Web Locks are required for safe slot replacement and standalone
arcade saving. Original Games must launch from their native main-site offer, not
by opening a downloaded game HTML file. Their pages write only a slot/generation/
offer-specific gameplay journal; the main app alone verifies and pays milestones.
No hidden/offline minigame earnings are promised. A previously paid journal that
is missing or inconsistent is not silently reinitialised.

If a write/readback becomes uncertain, that session pauses permanently. Do not
retry a payment, refund, reset, clear data or bypass the owner guard. Keep the
private backup and browser data; reload safely to confirm what actually saved.
A confirmed transport receipt, website publication and physical-device operation
are separate facts.

## Safari / Home Screen

1. Open the parent-approved HTTPS game URL directly in Safari.
2. Use Share → Add to Home Screen if wanted.
3. Open online once and let offline setup finish before trying offline mode.
4. Tap an audio control to permit sound; keep your existing mute/volume choices.

The offline worker caches only this exact named static release. It does not cache
private saves, cross-origin requests, unknown URLs or queries. Updates wait until
old clients close; they do not forcibly replace a live hand. Repair accepts only
an entire checksum-identical bundle, never a mixture of releases. Cache cleanup
is restricted to this app's own prefix and hosting directory, not localStorage.

An HTML attachment or Files/Telegram preview is not an installable Safari URL.
Insecure LAN HTTP does not enable service workers; localhost is only an exception
on that same device. File/content previews and unsupported browsers have no
universal storage-durability guarantee. Browsers can evict storage, so keep exports.
Local automated Chromium evidence is not a physical iPad/Safari/Android test,
and numerical audio checks are not a human listening test.
