Balatro Online - R167 update (NOT a standalone website)

This update requires the existing R156 Balatro Online website. If you do not
have R156, do not use this ZIP by itself.

1. Before updating, back up your save using the game's existing save export
   controls. Keep the downloaded backup somewhere safe.
2. Extract the six website files into the SAME existing project root (the
   folder that already contains index.html). Replace index.html and sw.js.
   Add the three new .js files as named. The included your-recording-r156.m4a
   is unchanged and belongs in that same folder. This README is not a site file.
3. Keep all other R156 files and the same HTTPS address (origin). Keep your
   browser data: do not clear site data, reset your save, or migrate it.

This ZIP does not deploy anything.
