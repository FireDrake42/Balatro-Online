BALATRO ONLINE — R168: 39 SWITCHES
Incremental update for R167 only. This is not the full game or a save file.

Before updating
1. In your current game, use Settings > Export Progress > Download JSON for
   each slot you use. Check that the backup files downloaded and keep them private.
2. Close all Balatro Online tabs, including any Original Games tabs. Keep a copy
   of your current R167 website files too.

Apply the update
3. Extract the ZIP into the root of your existing R167 website folder. Keep the
   folder names. Replace only the matching files from the ZIP; don't delete any
   old assets. In particular, keep the existing R156 soundtrack files.
4. Use the same site address (the same Vercel origin if that's where you play).
   Don't open the extracted index.html as a local file. This ZIP does not deploy
   the site for you. After you update the site, reopen the same game address.
   Never clear browser data or reset progress to apply this update. If something
   looks wrong, stop and keep your backup rather than starting over.

What's in R168
- Up to 39 switches at actual Player Level 20: 31 Display & extras and 8 Power.
  Some need their matching game modules. Each feature keeps its own unlock.
- Classic styling for both Levels views, using current XP and unlocks.
- Tools off hides the table shortcut but keeps Level 10 Deal usable in Settings.
- No tested FPS gain in Opera. The new 220906 recording is not included.
  This doesn't remove loot or the fictional battery's drain, charging or blackouts.
