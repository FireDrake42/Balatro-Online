Read-only game storage sizes

Diagnostic only — this does not fix storage or confirm a save. Keep your paused game tab open. Do not retry rewards, reload that tab, clear data or delete backups.

Checking this page's origin before reading size metadata…

Only source-verified, fixed game-bank keys are queried. Values, photos, models and slot contents are never shown, parsed or exported. Other keys and dynamic ending-backup IDs are not queried. The subtotal is not full-origin usage or available quota.

Lengths are UTF-16 code units. Estimated bytes = 2 × (known key length + value length), not the browser's real quota accounting. Reads are not an atomic snapshot. No game code, writer claims, trial writes, network calls or recovery actions run here.
